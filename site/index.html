AI4IA — a governed, multi-model agentic chat platform on Azure

A multi-model, multi-region agentic chat application for personal use and customer demos. A Next.js web app, a FastAPI governance backend, a SimpleL7Proxy model gateway, and Azure infrastructure as Bicep — all in one monorepo, all deployed through azd. This portal explains what it is, how it fits together, what it runs on, and whether it is healthy right now.

What it is

The web frontend calls the FastAPI backend; the backend owns auth, session state, tools, memory, document/library access, usage metering, and all model routing. Compatible HTTP/SSE calls go SimpleL7Proxy -> APIM -> Foundry; Voice Live uses the FastAPI relay -> APIM path.

🎯 Purpose & principles

Gateway-first: HTTP/SSE uses SimpleL7Proxy -> APIM; realtime uses the relay -> APIM.

Catalog-driven: infra/models.json is the deployment source of truth.

Feature-gated: advanced surfaces fail closed and default safe.

Identity-first: Azure data planes use managed identity; scoped hop keys remain app secrets.

Cosmos is canonical; derived stores (memory, search, chunks) are rebuildable.
