Deployment snapshot

The deployed footprint of AI4IA in rg-ai4ia-slurmfactory, generated from Azure Resource Graph (the authoritative inventory), Azure Resource Health, and probes of the public web and model-proxy endpoints.

This is a static snapshot, not a live poll: a scheduled GitHub Actions workflow regenerates status.js using the deployment's federated (OIDC) identity, then republishes this page. Health is derived from provisioning state, Resource Health availability, and endpoint reachability.

Public endpoints

A 200/redirect or an auth challenge (401/403) both prove the ingress is serving. The model proxy is scale-to-zero, so a cold-start timeout reads as “no response”, not a confirmed outage.

Azure resources

Every resource in the resource group, grouped by role. Health reported means Azure Resource Health positively reported the resource as available; provisioned means it exists and has not failed, but publishes no availability state — most Azure resource types never do. Existence is not evidence of health, so the two are counted separately.
