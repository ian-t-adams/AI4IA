    Permissions (RBAC)

    Azure service data planes use managed identities and scoped role assignments. The gateway currently uses three independently scoped APIM subscription keys: proxy-ingress (FastAPI to proxy), proxy-to-model (proxy to APIM), and realtime (FastAPI to APIM), plus an optional fourth for Speech Voice Live. All are stored only as Container App secrets. Azure data planes use managed identity; Application Insights uses its scoped connection string when telemetry is enabled. No Foundry account keys or SQL passwords are used at runtime.
